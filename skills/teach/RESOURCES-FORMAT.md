# RESOURCES.md Format

Optional scaffolding only. Create `RESOURCES.md` only when multiple high-trust sources will be reused across lessons. For a single lesson, cite sources inline in the Markdown file.

## Template

```md
# {Topic} Resources

## Knowledge

- [Paper / Book / Doc title](url)
  What it covers. Use for: when to reach for it.

## Wisdom (Communities)

- [Community](url)
  Why the signal is high. Use for: what kind of question belongs there.
```

## Rules

- High-trust only.
- Annotate every entry with one use-case line.
- Prune wrong or shallow sources instead of accumulating them.
- If a needed source is missing, list it under `## Gaps`.
