# Learning Record Format

Optional scaffolding only. Create `learning-records/` only when the user demonstrates non-obvious understanding, states durable prior knowledge, or corrects a misconception that should change future lessons.

Files: `learning-records/0001-slug.md`, incrementing.

## Template

```md
# {Short title}

{1-3 sentences: what is now known, and why future lessons should change because of it.}
```

## Write one when

1. The user demonstrated real understanding of something non-trivial.
2. The user disclosed prior knowledge that should not be re-taught.
3. A misconception was corrected.
4. The goal shifted because of what was learned.

## Do not write one for

- Material that was merely covered
- Session activity logs
- Content already clear from the lesson itself
