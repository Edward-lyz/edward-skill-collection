# publish-doc - 发布文档

发布指定的知识库文档，使编辑后的内容对读者可见。

## 用法

```bash
ku publish-doc --doc-id <DOC_ID> --username <USERNAME>
```

## 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| doc-id | string | 是 | 文档ID |
| username | string | 是 | 操作人用户名 |

## 使用说明

- 该命令用于显式发布文档，不属于正文编辑命令的一部分。
- 常见场景是文档编辑完成后，单独执行发布以让最新内容生效。
- 若命令返回 `发布完成`，表示发布已经完成。
- 若命令返回 `发布已提交，将在约30秒内执行发布，预计于 HH:mm:ss 执行`，表示发布已提交并进入延迟执行流程。

## 响应说明

| 字段 | 说明 |
|------|------|
| returnCode | 业务返回码，`200` 表示成功 |
| returnMessage | 返回消息 |
| result.message | 发布结果消息，常见值为 `发布完成` 或 `发布已提交...` |
